# Warwick Asian Hub

I am the Tech Executive for Warwick Asian Society, and I want to build a modern, polished website for the society.

Overall Design Direction

Create a sleek, premium, modern website that combines Indian/Asian cultural design elements with contemporary web design. The site should feel elegant and professional rather than overly decorative.

Use a purple and gold colour palette as the core visual identity. Incorporate subtle Indian-inspired elements such as:

Rangoli-inspired patterns

Indian geometric motifs

Subtle ornamental borders and decorative shapes

Elegant patterns inspired by traditional Indian textiles and architecture

Small cultural details throughout the UI without making the site feel cluttered

The design should feel modern, sophisticated, energetic and welcoming, while clearly representing an Asian society at Warwick.

Website Structure

For the initial version, build these four pages:

About

Introduce Warwick Asian Society

Explain who we are, what we do and our purpose

Include sections for our mission, community and what members can expect

Leave suitable areas for images and logos that I will provide later

Meet the Execs

Create a visually appealing executive team section

Each executive should have:

Photo

Name

Position/role

Short bio

Optional social media/contact links

Use cards or another polished layout that makes the team easy to browse

Events

Create a dedicated events page

Display upcoming and past events in an attractive way

Include event cards with space for:

Event name

Date

Time

Location

Description

Event image

Registration/ticket button

Design the page so that it can easily be connected to a real event system later

Membership

For now, this page should be frontend-only

Create a polished membership/registration experience

Include information about the benefits of joining the society

Include a clear call-to-action to join

The actual membership functionality/backend does not need to be implemented yet

Structure it so that a real membership system can be integrated later

UX/UI Requirements

Make the website fully responsive across desktop, tablet and mobile.

Use smooth animations and transitions, but keep them subtle and professional.

Prioritise clean typography and strong visual hierarchy.

Make navigation simple and intuitive.

Include a polished navbar and footer.

Use consistent spacing, buttons, cards and design components across all pages.

Make the website feel like a real university society website rather than a generic template.

Use accessibility-friendly colour contrast and readable typography.

Ensure the design is easy to expand with additional pages and functionality later.

Branding & Assets

I will provide the Warwick Asian Society logo, photographs, executive photos and other branding assets later.

For now:

Use appropriate placeholders where images will eventually go.

Make the image areas visually integrated into the design.

Do not permanently hard-code placeholder images into the visual identity.

Structure the website so my supplied assets can easily replace the placeholders.

Important Design Principle

The goal is “modern Indian-inspired design”, not a stereotypical or overly colourful Indian theme. Think premium university society + subtle Indian cultural identity.

Use purple and gold as the dominant colours, with Indian-inspired patterns and rangoli elements used strategically as accents.

The final result should feel sleek, premium, culturally distinctive, and professional enough to represent Warwick Asian Society publicly.

Build the four pages now, with clean reusable components and a structure that will allow us to add real data, images, events, authentication and membership functionality later.
